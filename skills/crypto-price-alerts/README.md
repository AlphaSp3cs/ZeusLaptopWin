## Purpose
Automated price alert system for crypto assets with push notifications and webhook integration.

## Features
- Set price alerts for BTC, ETH, and altcoins
- Push notifications (Telegram/Discord/Email)
- Webhook integration for Zeus order triggers
- Historical alert tracking
- Multi-exchange arbitrage detection
